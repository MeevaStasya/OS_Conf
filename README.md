# Лабораторная работа 1: Сбор метаданных ОС


## Цель
Реализовать кроссплатформенный сбор параметров ОС на Python с сохранением в JSON.

## Обоснование выбора модулей
- **Стандартная библиотека (`platform`, `os`, `sys`)**: для получения базовых параметров без вызова утилит ОС.
- **`psutil` (внешний)**: единственный корректный кроссплатформенный способ получить метрики CPU/RAM/Disk/Uptime без парсинга платформозависимых файлов (`/proc`, WMI) и без запуска внешних команд (`uptime`, `free`). Это соответствует требованию «использовать внешние модули с обоснованием».

## Инструкция по запуску
1. Установите зависимость: `pip install psutil`
2. Запустите: `python lab1_os_info.py`
3. Результат: файл `os_info.json` в папке со скриптом.

## Требования соблюдены
- [x] Нет вызова утилит ОС (`subprocess`, `os.system`).
- [x] Базовые данные — только стандартная библиотека.
- [x] Расширенные данные — `psutil` с обоснованием.
- [x] Вывод в структурированный JSON.
