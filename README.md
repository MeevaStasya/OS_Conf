# Описание работы.
Скрипт собирает информацию об операционной системе, аппаратном обеспечении и окружении, затем сохраняет все данные в файл `os_info.json`.

## Выводимые данные.
**Базовая информация:**
- Название операционной системы;
- Версия и номер сборки ОС;
- Архитектура процессора;
- Модель процессора;
- Сетевое имя компьютера (hostname);
- Версия Python;
- Текущая рабочая директория;
- Домашняя директория пользователя;
- Разделитель путей в ОС;
- Время сбора данных.

**Расширенная информация (требует `psutil`):**
- Количество логических и физических ядер процессора;
- Объём оперативной памяти (всего / занято);
- Объём диска (всего / занято);
- Время работы системы (uptime в секундах);
- Список сетевых интерфейсов.

## Используемые модули.
Для выполнения выбраны стандартные модули Python и один внешний модуль:

- Модуль `json` (стандартный);
- Модуль `os` (стандартный);
- Модуль `platform` (стандартный);
- Модуль `sys` (стандартный);
- Модуль `datetime` (стандартный);
- Модуль `typing` (стандартный);
- Модуль `psutil` (внешний).

## Используемые функции и их назначение.
- `platform.system()` возвращает название операционной системы;
- `platform.version()` возвращает номер версии и сборки ОС;
- `platform.machine()` возвращает архитектуру процессора;
- `platform.processor()` возвращает модель процессора;
- `platform.node()` определяет сетевое имя компьютера;
- `sys.version` возвращает полную версию интерпретатора Python;
- `os.getcwd()` возвращает текущую рабочую директорию;
- `os.path.expanduser("~")` возвращает путь к домашней директории пользователя;
- `os.path.sep` возвращает разделитель путей в текущей ОС;
- `datetime.now().isoformat()` возвращает текущее время в формате ISO 8601;
- `psutil.cpu_count(logical=True/False)` возвращает количество логических/физических ядер процессора;
- `psutil.disk_usage()` возвращает информацию о занятом и свободном месте на диске;
- `psutil.boot_time()` возвращает время загрузки системы (для расчёта uptime);
- `psutil.net_if_addrs()` возвращает список сетевых интерфейсов;
- `json.dump()` записывает словарь в файл формата JSON в кодировке UTF-8 с отступами.
